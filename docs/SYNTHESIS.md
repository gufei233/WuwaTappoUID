# 合成说明

- `wt合成` 或 `wt合成 升阶`：同品类、同稀有度的10件多余物品升阶。
- `wt合成 同阶`：同品类、同稀有度的5件多余物品同阶合成。
- 可组合 `角色`、`配件` 或 `表情` 参数限定品类，顺序不限。例如 `wt合成 角色` 仅角色升阶，`wt合成 同阶 角色` 或 `wt合成 角色 同阶` 仅角色同阶，`wt合成 升阶 配件` 仅配件升阶。
- 不指定品类时处理全部品类。每种物品至少保留1件；本轮始终只执行指定模式和品类，不自动切换。
- 跳过官方背包中已收藏物品的全部数量；取消收藏后，其重复件才会重新参与合成。插件不提供收藏操作。
- 每次成功后刷新背包，再选择下一组材料，直到材料不足。
- 结果图对本次合成开始前未拥有的物品标记NEW，同种产物只标记第一件；复用现有背包读取，不增加请求。
- 合成与开箱共用账号锁。结果不明或背包回读异常时停止，不自动重发；已成功结果仍会汇总。

使用官方接口 `/api/frontend/assets/synthesis` 和 `/api/frontend/assets/synthesis/same-level`。合成流水保存在 `wt_synthesis_record`，不计入宝箱任务成功数。
